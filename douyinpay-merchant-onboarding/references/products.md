# 产品、类目与材料规则

本文定义当前 Skill 可执行的抖音支付产品范围、经营类目和材料要求。

## 当前支持产品

| 用户侧名称 | product code | 适用场景 | 当前支持状态  |
|---|---|---|---------|
| Native 支付 / 电脑网站扫码支付 | `CO_PAY_NATIVE` | PC 网站、网页应用、未上线网站测试场景中的扫码支付 | ✅ 当前可签约 |

产品签约当前**只支持 Native 支付**。如果用户要求签约 H5、APP、JSAPI、小程序等其他支付产品，必须说明当前不支持签约，不得编造命令或产品码，并引导用户前往 [抖音支付商家平台](https://pay.douyinpay.com) 使用非个人主体入驻并在【产品中心】自行开通/签约对应产品。

## 其他支付产品处理规则

| 用户诉求 | Skill 处理 |
|---|---|
| 签约 Native 支付 / 电脑网站扫码支付 | 使用 `CO_PAY_NATIVE` 继续当前 CLI 签约流程 |
| 签约 H5 支付 | 引导至抖音支付商家平台【产品中心】开通/签约，不在 Skill 内执行 |
| 签约 APP 支付 | 引导至抖音支付商家平台【产品中心】开通/签约，不在 Skill 内执行 |
| 签约 JSAPI 支付 | 引导至抖音支付商家平台【产品中心】开通/签约，不在 Skill 内执行 |
| 询问其他产品能力 | 可解释当前 Skill 范围，但不能推荐或编造产品码 |

标准话术：

```text
当前产品签约仅支持 Native 支付（CO_PAY_NATIVE）。
如果您需要签约 H5 / APP / JSAPI 等其他支付产品，请前往抖音支付商家平台：https://pay.douyinpay.com，在【产品中心】选择对应产品完成开通/签约。
```

## 经营类目

个人入驻默认：

```text
其他互联网服务
```

规则：

- 个人商户扫码入驻时无需用户手动选择类目；
- 不在本地硬编码复杂 MCC 码表；
- 禁止对用户进行类目推荐或编造MCC值。

## Native 支付材料

Native 支付产品签约需要两张截图：

| 截图 | 内容要求 | 用途 |
|---|---|---|
| 域名首页截图 | 展示网站 / 应用主界面、导航、核心功能入口 | 证明业务页面存在 |
| 销售/服务页截图 | 展示商品或服务详情，建议包含价格、服务说明或交易入口 | 证明存在交易场景 |

上传命令：

```bash
dypay-cli file upload <file> --file-type JPG --json
```

上传结果使用 `file_url`。

## 抖音开放平台 AppID

- AppID 固定使用：`awt8ebrmwk7b3ebi`；
- 不要求用户提供 AppID；
- 不要求用户手动绑定 AppID；
- 不向用户询问或确认 AppID。
