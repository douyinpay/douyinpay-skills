# 证书密钥配置指引

本 Skill 只提供流程指引，不在对话中处理敏感密钥。密钥、私钥、接口加密密钥等高敏信息只能在抖音支付商家平台中处理。

参考文档：<https://pay.douyinpay.com/wiki/66aa57118a7da602efb9bc2f/67bee79569cf2a053adb0a68>

## 配置模式

| 项目 | 规则                                      |
|---|-----------------------------------------|
| 支持模式 | 证书模式                                    |
| 不支持 | 普通公私钥模式                                 |
| 商家平台动作 | 生成 CSR、下载商户加签私钥、申请证书、查看商户证书序列号、设置接口加密密钥 |
| Skill 动作 | 指引、检查用户确认、输出交接状态；不生成、不接收、不保存密钥          |

## 关键概念

| 概念 | 说明 | 安全要求 |
|---|---|---|
| 商户 API 证书 | 商户申请接口加签证书时，经抖音支付平台认证并颁发的证书，包含商户号、公司名称、公钥信息。平台会根据证书对商户请求验签。 | 请妥善保管 API 证书文件，防止泄露。 |
| CSR（证书请求串） | 申请商户 API 证书前需要生成的证书请求文件。生成 CSR 的同时会生成对应私钥。 | CSR 可提交到商家平台；私钥必须由商户自行安全保存。 |
| 商户接口加签私钥 | 生成 CSR 时产生，对接抖音支付服务端 OpenSDK 时用于请求加签。 | 平台不会替商户保存私钥；严禁发送到对话区。 |
| 平台公钥证书 | 抖音支付平台侧证书，用于商户侧验签平台应答或回调。 | 在商家平台下载；后续 SDK按需使用。 |
| 接口加密密钥 | 用于对抖音支付平台回调通知等敏感信息进行解密。 | 严禁发送到对话区。 |
| 商户证书序列号 | 商户构造请求时声明所使用证书的标识，抖音支付据此选择商户证书进行验签。 | 可从密钥管理列表查看。 |

## 关键字段

| 字段 | 是否必填 | 来源                                           | 对话处理规则 |
|---|---|----------------------------------------------|---|
| 商户证书序列号 | 是 | 抖音支付商家平台 → 产品中心 → 开发者配置 → 密钥管理，证书列表表格中展示     | 不建议在公开对话中长期保留 |
| 商户接口加签私钥 | 是 | 生成 CSR 时下载/保存的私钥文件，在本地文本编辑打开                 | 严禁在对话中发送 |
| 接口加密密钥 | 是 | 抖音支付商家平台 → 产品中心 → 开发者配置 → 密钥管理 → 接口加密密钥 → 查看 | 严禁在对话中发送 |

## 标准引导话术

当进入密钥配置阶段，使用以下话术：

```text
请前往抖音支付商家平台：https://pay.douyinpay.com
登录时请切换为【扫码登录】，使用抖音 App 扫码登录商家平台。
登录后进入【产品中心】→【开发者配置】→【密钥管理】，跟随密钥证书快捷引导完成：

1. 申请商户证书；
2. 下载并妥善保存商户接口加签私钥；
3. 查看商户证书序列号；
4. 设置并查看接口加密密钥；

⚠️ 请不要把商户接口加签私钥或接口加密密钥发送到对话区、代码仓库、公开文档、IM 或邮件中。
```

## 用户操作步骤

1. 打开抖音支付商家平台：<https://pay.douyinpay.com>。
2. 在登录页切换为【扫码登录】，使用抖音 App 扫码登录。
3. 登录后进入【产品中心】→【开发者配置】→【密钥管理】。
4. 点击「设置」。平台会要求安全验证，用户可通过短信验证码或操作密码完成验证。
5. 打开「密钥证书快捷引导」。如果当前没有密钥证书，平台会自动打开该引导。
6. 在引导中生成私钥与 CSR(证书签名申请文件)。
7. 下载私钥。
   - 平台不会存储私钥；
   - 必须先下载并妥善保存私钥，才能进行下一步；
8. 上传 CSR。
   - 快捷引导中可点击「确定使用该 CSR 文件」自动上传上一步生成的 CSR；
   - 若中途出错或忘记下载私钥，可点击重新生成来重置引导流程。
9. 完成证书申请后，在证书列表中查看并记录商户证书序列号。
10. 设置接口加密密钥。
    - 接口加密密钥用于加密/解密敏感信息，尤其是回调通知解密；
    - 后续也可在密钥管理页面查看。

## Skill 禁止行为

```text
❌ 禁止要求用户粘贴私钥
❌ 禁止要求用户粘贴接口加密密钥
❌ 禁止生成密钥对或给出 openssl、Java 等本地生成命令/脚本
❌ 禁止把敏感字段写入状态文件
❌ 禁止把敏感字段写入项目代码或环境文件
```

## 误贴敏感信息时的处理

如果用户在对话中粘贴私钥、接口加密密钥或完整证书材料：

1. 立即停止当前流程；
2. 告知用户该密钥应视为已泄露；
3. 建议用户前往商家平台重新生成/轮换证书与密钥；
4. 不复述、不保存、不处理该敏感内容；
5. 待用户完成轮换后再继续。

## 配置状态

只确认用户是否已在抖音支付商家平台完成证书密钥配置，后续支付接入所需校验由支付集成 Skill 处理。

| 状态 | 含义 |
|---|---|
| `not_started` | 用户尚未开始配置 |
| `merchant_platform_confirmed` | 用户确认已在抖音支付商家平台完成证书密钥配置 |
| `unknown` | 当前无法判断配置状态 |

未达到 `merchant_platform_confirmed` 前，不应进入支付集成。

## 常见失败恢复

| 场景 | 处理                                      |
|---|-----------------------------------------|
| 商户证书序列号为空 | 引导回密钥管理列表查看证书序列号 |
| 未下载私钥 | 如果仍在快捷引导中，先下载私钥；若已错过或无法找回，按平台流程重新生成/轮换证书 |
| 私钥为空 | 引导回商家平台重新生成私钥证书，提醒不要发到对话                       |
| 接口加密密钥为空 | 引导回密钥管理 → 接口加密密钥 → 查看复制；提醒不要发到对话   |
| 私钥格式错误 | 引导重新在商家平台生成                             |
| 接口加密密钥格式错误 | 引导检查密钥串完整性并重新提交                         |
| 已存在配置 | 默认不覆盖；要求用户确认复用或重新配置                     |
