# FAQ

## 为什么只支持 Native 支付 / CO_PAY_NATIVE？

当前产品签约能力只支持 Native 支付（`CO_PAY_NATIVE`）。如果需要签约 H5、APP、JSAPI等其他支付产品，请前往 [抖音支付商家平台](https://pay.douyinpay.com) 使用非个人主体入驻并在【产品中心】自行开通/签约对应产品。

## 我没有绑定银行卡，可以入驻吗？

个人主体入驻结算银行卡是可选项。无储蓄卡或仅有信用卡不阻断入驻，但入驻后暂时无法提现，需要前往商家平台补充绑定储蓄卡。

## 为什么不能在对话中粘贴私钥或接口加密密钥？

私钥和接口加密密钥属于高敏感支付材料，一旦进入对话、日志、代码仓库或 IM，就可能被缓存、索引或泄露。只引导用户在抖音支付商家平台完成配置，不在对话中接收这些内容。

## 密钥证书推荐怎么配置？

优先使用抖音支付商家平台【产品中心】→【开发者配置】→【密钥管理】里的「密钥证书快捷引导」。该引导会串联生成私钥与 CSR、上传 CSR、下载接口加签证书、下载平台公钥证书、设置接口加密密钥。平台不会存储私钥，必须下载并妥善保管。

## 如果我忘记下载私钥怎么办？

如果还在快捷引导中，可先下载私钥后继续；如果已经无法找回私钥，应按商家平台流程重新生成/轮换证书和密钥。不要继续使用无法确认私钥来源的配置。

## 如果我已经粘贴了私钥怎么办？

应视为已泄露。请立即到商家平台重新生成/轮换证书和密钥。不要继续使用已粘贴过的密钥。

## 签约状态为审核中怎么办？

表示正在审核中。不要重复提交签约申请，稍后再次执行：

```bash
dypay-cli sign query-by-code --product-code CO_PAY_NATIVE --json
```

## 签约被驳回怎么办？

查看返回的驳回原因。常见原因包括截图不清晰、截图内容不符合要求。按原因修复后，经用户确认再重新提交。

## 抖音支付有测试环境吗？

抖音支付当前按生产体系接入，调试时请使用小金额、受控账号，不要批量发起真实交易。
